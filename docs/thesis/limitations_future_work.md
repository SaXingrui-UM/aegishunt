# Limitations and future work

Evidence level: **documented limitation / not evaluated**.

See [Consolidated limitations](../limitations.md). Priority future work:

1. licensed public benchmark and independent multi-site enterprise evaluation;
2. untouched independent anomaly/fusion holdouts;
3. authenticated, authorized, TLS-protected multi-user interface;
4. independent durable control plane and production database/queue;
5. exact resumable stream checkpoints where required;
6. signed packages/images, SBOMs, immutable base digests, secrets management;
7. independent final security assessment and penetration test;
8. model/drift monitoring and human-approved retraining governance;
9. privacy, retention, deletion, backup, and disaster-recovery policy.

These items are future work, not partially implemented production features.
