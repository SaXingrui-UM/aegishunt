# Discussion evidence

Evidence level: **interpretation constrained by repository evidence**.

The implementation demonstrates that deterministic packet-to-flow processing,
dual-engine scoring, explicit policy fusion, evidence-rich alerting, bounded
correlation, proposed hypotheses, and analyst case management can coexist in a
reproducible local prototype.

The strongest conclusion is systems integration and evidence discipline, not
detection superiority. Supervised correction proves why optional numeric
metrics need explicit missing-value semantics. LOF's lack of independent
holdout prevents a production/frozen claim. Fusion's family-macro LOAO deficit
and missed families contradict a superiority claim. Deterministic templates
improve auditability but do not prove threat intent.

Deployment findings show the value of bounded inputs, exact artifact inventory,
single-writer semantics, and API-only UI access. They also expose the gap to
production authentication, distributed durability, supply-chain attestation,
external evaluation, and independent security testing.
